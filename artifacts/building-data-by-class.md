# 六职业建筑数据总表（原版《人族无敌 III 3.0 终极版》提取数据）

> 生成时间：2026-11-20　数据来源：`content/original-3.0/data.json`（原始 SLK）、`gameplay.json`、`presentation.json`、`functions.json`（JASS `Trig_LevelUp`）、`artifacts/profession-parity-audit.json`。共 **6 职业 × 40 形态 = 240 条**，其中农民可直接建造 **66** 座。

---

## 一、通用规则

### 1. 等级与形态

- 每职业 **11 座可直接建造**：4 座 1 档基础塔 → 4 座 2 档塔 → 2 座 3 档高级塔 → 1 座终极建筑。
- 每座非终极塔有 **Lv1 / Lv2 / Lv3** 三个形态；每职业另有 **3 条链**（2 档 2 条 + 3 档 1 条）可花资源升到 **LvMax**，前提是先造出本职业终极建筑（目标形态 `Requires` 指向终极建筑）。
- 另有 **6 个套装形态**（3 个初级 + 3 个对应高级），由装备/套装触发，不可直接建造。
- 合成：10 条链 × 3 形态 = 30，加 3 个 LvMax、6 个套装、1 个终极 = **40 形态/职业**。

### 2. 建造价格与建造条件

- 价格字段为原始 `goldcost`（金币），木材 `lumbercost` 在本图全部为 0；人口为 `fused`；建造时间为 `bldtm`（秒）。
- `Requires`（建造条件）是**前置塔的 Lv3 形态**：必须先拥有并升级出该前置塔，才可建造/升级到本形态。1 档基础塔无前置。
- 野蛮人马加爵另有 `e007`「只能建造 1 个马加爵」的数量限制。
- **手动升级**（`Upgrade` 字段）不是补差价：按**目标形态的完整 `goldcost`** 收费，加上目标形态人口差额，耗时目标形态 `bldtm`，并重新校验目标形态的 `Requires`（见 `engine/equipment.js:85-99`）。每职业 9 条，全图 54 条。

### 3. 功勋（经验）体系

- **获取**：每次由建筑击杀敌人（玩家 8—11 死亡事件），该建筑功勋 `+= 当前波次 + 2`（`Trig_LevelUp_Actions` 首行）。
- **触发**：条件为「功勋 ≥ 阈值」且「功勋 < 波次 + 阈值 + 2」，即**首次跨过阈值的那次击杀**才晋升，避免重复触发。
- **快速模式**（`udg_nokuaisumode = false`）取消阈值，每次击杀都可能成长/领悟。
- 领悟类技能为随机触发：`GetRandomInt(1, udg_jinengsjlv) == 1`。
- 正常模式阈值（与 `engine/progression.js:2-29` 一致）：


| 阶段 | 触发形态 | 功勋阈值 | 结果 |
|---|---|---:|---|
| 1 | 1 档 Lv1（`level1[1..24]`） | 150 | 晋升为 Lv2（`level2`）；套装初级技能 → 中级 |
| 2 | 1 档 Lv2、2 档 Lv1（`level2[1..48]`） | 250 | 晋升为下一形态；随机领悟 Lv1 增益技能 |
| 3 | 套装初级形态（`levelT1`） | 400 | 套装中级技能 → 高级 |
| 4 | 2 档 Lv2、3 档 Lv1（`level3[25..72]`） | 500 | 晋升为下一形态；随机领悟 Lv2 增益技能 |
| 5 | 3 档 Lv2（`level4[49..72]`） | 800 | 晋升为 Lv3（`level5`）；随机领悟 Lv3 增益技能 |
| 6 | 1 档 Lv3 六座指定塔 | 1000（魔剑士步兵、盗贼扒手为 800） | 领悟「牺牲」类终极技能 |
| 7 | 六职业终极建筑 | 5000 | 领悟「强化 / 夺命 / 利滚利」类技能 |
| 8 | 游侠后羿 `h043` | 10000 | 额外领悟「强弩(光环)」 |
| 特例 | 魔剑士喷火兵 `h073→h072→h071` | 250 / 400 | 按施法次数晋升（不吃击杀功勋） |

### 4. 技能等级

- 建筑技能由 `abilList` 给出自定义技能 ID，等级数取自 `abilityData[code].levels`。本图多数职业技能是**每个建筑阶段一个独立 ID**，所以 `levels` 常为 1；技能名里的 `(Lv1)/(Lv2)/(LvMax)` 表示它对应的建筑阶段，不是技能自身层数。
- 原生复用技能（如重击 `AHbh`）可有多级；同一光环 ID 来自不同等级来源时，引擎保留较高等级。
- 套装技能按 `jinengT1/T2/T3` 与 `jinengS1/S2/S3` 在功勋 150 / 400 时替换升级；成长领悟的技能由 JASS `UnitAddAbilityBJ` 追加。

### 共同规律

- **价格梯度**：1 档 100—1450 金，2 档 1000—6500 金，3 档 3000—10000 金，终极 13000—16000 金（各职业略有差异）。

- **人口**：多数 1 档 1—3，2 档 1—4，3 档 1—4，终极 4—5；人口上限 `FoodCeiling=65`。
- **建造时间**：主要建筑 30 秒，部分 20—50 秒；手动升级沿用目标形态 `bldtm`。
- **技能配置**：66 座可建造建筑全部带 `A01H 出售`、`Avul 无敌的`；65 座带 `A00U 功勋值`（仅猎人长者 `h00P` 缺此按钮）；外加 1—2 个职业主动/被动技能。
- **功勋成长**：原版仅建筑本体击杀成长；本项目按需求扩展为召唤物击杀回溯归属本体（见 `docs/building-progression.md`）。

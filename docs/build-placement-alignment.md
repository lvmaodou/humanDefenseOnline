# 建造位置规则与原图对齐

原图 `content/original-3.0/script.j` 没有“距出生点 2304 码内才能建造”的判断。原脚本中的 `2304` 出现在区域坐标中，不是建造半径；两处 `EVENT_PLAYER_UNIT_CONSTRUCT_FINISH` 注册处理建筑专属效果，没有按玩家出生点限制位置。因此移除重构版本中自行加入的圆形防区限制及圆圈提示。

六个职业建造者提供的 66 个建筑在原始单位表中均使用：

- `pathTex = PathTextures\4x4SimpleSolid.tga`，占用 4×4 个 32 码寻路格，即 128×128 码。
- `preventPlace = unbuildable`，不能覆盖地图 WPM 中禁止建造的格子。
- 各自的 `Requires`、金币、木材、人口消耗条件。

客户端预览和服务端验证共用 `public/placement.js`，检测完整占地、地图边界和已有建筑重叠。已移除的建筑不继续占位。

原图套装说明中的 1200/99999 码是套装效果的激活距离，不作为建造位置限制。本次没有将它们加入建造判定。

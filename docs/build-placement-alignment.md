# 建造位置规则与原图对齐

原图 `content/original-3.0/script.j` 没有“距出生点 2304 码内才能建造”的判断。原脚本中的 `2304` 出现在区域坐标中，不是建造半径；两处 `EVENT_PLAYER_UNIT_CONSTRUCT_FINISH` 注册处理建筑专属效果，没有按玩家出生点限制位置。因此移除重构版本中自行加入的圆形防区限制及圆圈提示。

六个职业建造者提供的 66 个建筑在原始单位表中均使用：

- `pathTex = PathTextures\4x4SimpleSolid.tga`，占用 4×4 个 32 码寻路格，即 128×128 码。
- `preventPlace = unbuildable`，不能覆盖地图 WPM 中禁止建造的格子。
- 各自的 `Requires`、金币、木材、人口消耗条件。

WPM 禁建位是 `0x08`，不是旧实现读取的 `0x04`（禁止飞行）。原始岩石道路的典型值为 `72 = 64 + 8`，草地典型值为 `64`，这也与地形 SLK 中岩石 `buildable=0`、草地 `buildable=1` 相符。

建造面板可从未选中单位时的地面点击、己方农民信息面板的“建造建筑”按钮、战场“建造”按钮或 `B` 键打开。选中农民时普通地面点击仍只移动；退出选点后可直接再次点地面开始新的建造选择。建筑列表按原图造价由低到高显示，并就地标出当前缺少的前置建筑、金币、木材或人口；点击不满足条件的建筑时，地面预览说明具体原因，不会扣除资源或覆盖农民的移动操作。

客户端预览和服务端验证共用 `public/placement.js`，检测完整占地、地图边界和已有建筑重叠，并从原始装饰物的 `pathTex` 加载树木及装饰物占地。已移除的建筑不继续占位。

按当前贴边建造的交互要求，修正重构地形与原始 WPM 悬崖禁建带的边界差异：原图中值为 `202` 的悬崖格会覆盖一部分已经显示为上层草地的位置。当建筑完整的 128×128 占地位于同一上层可建表面时，允许贴边放置；使用与画面相同的地形三角形和高度采样检查完整占地。跨沟壑、岩石道路、明确禁建格、地图边界及物体占地仍然禁止。这是对当前重构画面的边缘适配，不修改原始 WPM 或单位移动寻路。

原图套装说明中的 1200/99999 码是套装效果的激活距离，不作为建造位置限制。本次没有将它们加入建造判定。

真实桌面、横屏手机和竖屏手机的操作回归：`npm run test:build`。

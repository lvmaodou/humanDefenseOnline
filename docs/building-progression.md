# 召唤物击杀归属与建筑功勋显示

核查日期：2026-11-19。依据 `content/original-3.0/functions.json` 中的 `InitTrig_LevelUp`、`Trig_LevelUp_Conditions`、`Trig_LevelUp_Actions` 及魔剑士喷火兵攻击触发器。

原地图的成长触发器仅接收玩家 8—11 的死亡事件，要求击杀者是存活建筑，并排除 `h073`、`h072`。它没有将水元素等召唤物的击杀归给召唤建筑。本次按玩家需求增加召唤物功勋归属，这是有意扩展原图行为。

## 归属与结算

- 原生召唤和 JASS 施法、攻击事件产生的辅助单位记录召唤来源；多层召唤沿来源链找到本体建筑。
- 建筑被原脚本晋升替换后保留替换关系，已有召唤物继续向晋升后的建筑提供功勋。没有召唤来源、来源已出售或死亡、来源改变玩家时，不按距离猜测归属。
- 只有功勋触发器看到归属建筑；其他死亡触发器仍接收实际击杀者，金币、玩家杀敌数和掉落各自只结算一次。
- 本体正在建造或手动升级时暂存功勋，完成后按每次击杀当时的波次结算，保留原脚本的建成奖励。暂存部分在面板中注明。
- 功勋增量、晋升替换、学习技能和快速模式继续运行原 JASS。`h073`、`h072` 按原攻击施法机制成长，召唤物击杀不重复增加这两种建筑的功勋。

## 界面

选中玩家建筑时，以当前功勋、下一阶段所需功勋及进度条替代生命条，并显示下一建筑或技能。普通晋升、套装技能提升、技能领悟和盗贼训练按各自阶段显示。纯资源升级显示累计功勋与升级按钮提示，不捏造经验门槛；成长完成后显示完成提示。

快速模式标明再击杀一只即可成长；喷火兵使用“技能功勋”标签。农民和召唤战斗单位继续显示生命，建筑的魔法、攻击和操作按钮保持可用。自动晋升后继续选中同一建筑的后继形态。

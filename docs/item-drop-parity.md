# 掉落物与原图核对

核对范围是当前地图的实际掉落池及操作流程，依据 `content/original-3.0/script.j`、`data.json` 和 `gameplay.json`。资源文件存在、脚本引用和实际运行分别验证，不能用“模型已下载”代替玩法验证。

## 哪些物品进入游戏

原版全量表有 297 个物品定义，本地图脚本直接引用或随机池涉及 19 件，其中常规击杀池只有 18 件套装建塔道具。每件都共用原版 TreasureChest 地面模型，名称、图标及建塔目标各自不同，并非每种装备都应有独立地面模型。

| 职业 | 三种组件与物品 ID |
| --- | --- |
| 野蛮人 | 棍 I004、拳 I005、刀 I006 |
| 猎人 | 攻 I00B、法 I00C、辅 I00D |
| 盗贼 | 杀 I007、偷 I00E、抢 I00F |
| 术士 | 云 I008、雷 I009、风 I00A |
| 游侠 | 冰 I001、毒 I002、火 I003 |
| 魔剑士 | 幻 I00G、术 I00H、武 I00I |

剩下的 I000 火焰之球仅由 `Trig_donghua_Actions` 剧情引用；该剧情触发器在原图初始化时禁用，不属于常规掉落，也不是开局自动赠送。携带时被动生效，可以丢弃、转交，不能主动使用。已取得的 TomeBrown 属于未被本图使用的原版物品资源，不加入随机池。原图未放置出售这些装备的商店，图鉴不能直接购买。

## 掉落条件

- `Trig_Add_Point_Func009C`、`Trig_Add_Point_Actions`：敌方玩家 8～11 的单位死亡时，只有 `udg_waves <= 45` 才抽取装备。标准模式两次随机判断同时成功（1/10 × 1/20），概率 0.5%；特殊、疯狂模式为 1/100，即 1%。第 46 波开始不再通过该触发器掉落。
- `ChooseRandomItemBJ(10)` 使用 `oldLevel=10` 且 `pickRandom=1` 的 18 件物品，等概率抽取，允许重复。一局不保证全部出现。
- 预放置的中立吉安娜另有 `Unit000018_DropItems`：首次有效死亡或转属时进行 8 次各 50% 的独立抽取，候选为 `Level=8` 的同一批 18 件道具，随后销毁该掉落触发器。它与波次掉落独立。

## 拾取、丢弃和使用

- 六职业农民均按原始 `AInv.DataA1=6` 使用六格物品栏；没有物品栏能力的建筑不能通过操作请求拾取装备。原图自定义拾取范围为 99999，沿用此值。
- 点击地面宝箱，或从农民面板的地面装备列表拾取。成功后地面模型移除，物品进入农民物品栏；满六格、已被别人拾取等情况失败且不复制物品。
- 在农民物品栏丢弃后，同一个物品句柄、类型和剩余次数保留，模型在农民所在位置恢复，队友可以重新拾取。
- 18 件装备使用原图 `AIbl` 能力建塔。选定有效地格后，农民会走到原图 100 码施法范围内；实际开工才消耗一次性道具。地形、占用、人口或路径不允许时保留道具；手动移动或丢弃会取消尚未开工的操作。
- 建造时长为原图能力的 5 秒，初级套装塔永久存在。再按原图目标单位的费用、人口与时间升级，三种正式组件满足职业、距离、模式要求后由原图触发器赋予套装效果和连接特效，详见 [职业套装](resource-and-equipment-flow.md)。

## 此次修复

1. 服务端传递原始地面模型、缩放和颜色；客户端真正加载 TreasureChest MDX、纹理及 Stand 动画，替换之前固定绘制的通用宝石。为原生模型配置点击体积，并在拾取、重置或异步加载完成过晚时释放资源；地图资源晚于状态抵达时也会补挂模型。
2. `CreateItemLoc` 正确更新 `bj_lastCreatedItem`；原图对物品下达的中立 smart 指令执行拾取，不再将物品错误存成攻击目标。
3. 被动火焰之球拒绝主动使用请求。物品剩余次数按源数据读取：被动/无限次物品为 0，不再伪造为 1；有限次道具只在成功使用后扣除。
4. 拾取容量读取原始物品栏能力，修复所有单位都被默认允许携带六件物品的问题。

- `npm test`：85 项通过。真实死亡事件覆盖标准/特殊概率分支、第 45/46 波边界、全部 18 个随机结果、中立吉安娜一次性掉落表；全部 18 件道具分别经过拾取、丢弃、重新拾取、建塔和升级；六职业套装及被动火焰之球也有运行验证。
- `npm run test:team`：独立随机端口服务端、桌面与竖屏手机两个 Chrome 客户端，验证原版宝箱加载、地面点击拾取、模型移除/恢复、队友转交、三塔摆放升级和猎人套装激活，浏览器错误为 0。测试结束关闭服务端。

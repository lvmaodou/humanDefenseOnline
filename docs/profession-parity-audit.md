## 再次逐建筑实战复查

本次对全部 240 个形态逐一新建独立运行环境，启用对应职业的原始触发器，对地面、空中、五种原版 Boss 和召唤物目标运行攻击与自动技能，再操作建筑初始主动技能。累计执行 346 次主动技能命令尝试、记录 15,325 次伤害事件，六职业均无脚本异常。每次主动命令是否成功、实际施法族、生成单位及移动/受击分类保存在 [逐建筑运行记录](../artifacts/profession-runtime-detail-audit.json)。命令尝试不等于成功施放，资源、目标与条件不满足时保留原规则拒绝结果。

静态清单也扩展为保存每个建筑、辅助施法者、召唤单位的完整原始对象字段，以及所有追踪技能的解析参数和画面字段；同时扫描它们的武器弹道引用，避免只统计建筑模型和技能 Art 而漏掉召唤物攻击。见 [全部职业详细原表](../artifacts/profession-parity-audit.json)。各职业的 3 个无攻击套装初级形态在源表中本来关闭武器，本次未将它们误判成攻击故障。

| 复查项 | 确认的问题及修复 |
|---|---|
| 召唤物受击分类 | 熊、树人、狼、水元素、地狱火、战士、民兵和炎魔使用 `movetp=fly`，但原表 `targType=ground`。现在移动仍遵循原移动方式，武器、技能与光环按独立的受击分类判断，地面武器不会漏打它们 |
| 猎人杀戮与 Boss | `A0B9` 的原表 `nonhero` 限制、提示中的“对 Boss 无效”此前未进入暴击计算。现在五种原图 Boss 均不会触发该技能的 99999 倍攻击 |
| 手动、自动与范围技能 | 统一应用原表阵营、地面/空中、非英雄、无敌、魔免、Locust 与建筑目标规则；无效手动目标在扣魔法、设冷却和触发 JASS 之前拒绝。分裂、冻结和多重箭也使用相应目标规则 |
| 技能等级 | 被动暴击、重击、光环与范围目标筛选读取当前等级；同一光环 ID 来自不同等级来源时保留较高等级，不因遍历顺序换成一级 |
| 闪电护盾 | 重复施放刷新同一载体上的原生护盾，保留原伤害节拍，不叠加多个伤害区，也不因不断刷新而永远不跳伤害；辅助施法者消失后护盾继续生效，并显示原护盾模型 |
| 死亡锁镣 | 原 `BuffID` 中第一项是没有模型的施法者状态，第二项才是目标锁镣。改为在目标胸部附加 `AerialShacklesTarget`，按普通/英雄时长清理 |

| 引导动作与断线恢复 | 单位快照保留引导技能及原动作属性。原模型持续施法姿态维持至引导结束，缺少对应动作时保留同一升级形态；断线后无需重放历史施法事件即可恢复姿态。引导效果保持同步，打断时停止原模型特效 |

## 已修复的差异

| 范围 | 原问题 | 修复后的行为 |
|---|---|---|
| 普通建筑升级 | 只有套装建筑能操作 Upgrade | 原表中 54 条升级关系均可操作，验证前置、资源、人口及升级时间；功勋晋升继续由原脚本执行 |
| 成长技能界面 | 单位学会技能后，界面仍只查初始技能表 | 按单位当前技能构建面板，补充脚本授予技能的名称、说明、费用和目标方式 |
| 主动与被动 | 部分原生被动被当作按钮，自动施法能力与默认开启状态混淆 | 区分主动技能、原生自动施法能力和 Unit.auto 默认状态；不再把出售按钮显示成被动技能 |
| 伤害结算 | JASS 的 ATTACK_TYPE_NORMAL 与武器 normal 混用，法术误受物理护甲影响 | 区分法术攻击类、普通武器类和伤害类型；脚本伤害不再自动叠加武器、装备加成 |
| 研究 | 射程与回复研究影响了不在适用表中的单位 | 仅按单位 upgrades 列表应用；补上猎人套装 R002 的弹射目标数 |
| 友军技能 | 原表 invulnerable 标签未识别，无敌建筑无法接受嗜血或恢复魔力 | 识别两种原始标签写法；友军施法按阵营与范围判定，魔力泉水可恢复友军魔法 |
| 野蛮人 | 穿刺距离、飞行时间与伤害字段混用；地狱火寿命取成落地延迟 | 穿刺沿路径命中；地狱火延迟落地，之后按独立寿命存在；永久献祭和魔免生效 |
| 猎人 | 群星坠落、诱捕辅助单位的命令未映射；弹射瞬间结算 | 补全原命令；月刃逐段飞行并衰减；毁天灭地的原生伤害、眩晕先于牺牲执行 |
| 盗贼 | 末日、兵工厂和暗影突袭被简化 | 末日标记死亡后召唤；工厂按间隔出兵、子兵独立计时；暗影突袭不随辅助施法者移除而停止；可设置集结点 |
| 术士 | 叉状闪电把距离当成持续伤害、眩晕时长 | 改为原字段规定的单次多目标伤害；霜冻、冰冻、凤凰火焰和暴风雪分别使用对应机制 |
| 游侠 | 多重箭限制了类型和数量，黑暗箭与多重箭同时触发，套装箭矢未结算 | 多重箭发射真实弹道；黑暗箭优先生效，死亡标记支持友军补刀；补齐冰箭、火箭和毒伤 |
| 魔剑士 | 吸星大法没有真实飞虫行为，治疗瞬时发生 | 按原表释放飞虫、限制同一目标围攻数量，积累伤害后返航治疗，结束时回收；Locust 保持不可直接操作 |
| 兽群冲撞 | 按区域随机扣血，没有移动碰撞 | 按出兽频率和延迟产生弹道，碰撞后按原表爆炸范围结算 |
| 套装附加属性 | 直接加在建筑身上的 AIat、火焰球、腐蚀球及毒伤只存在数据 | 单位技能和物品能力共同参与属性及攻击效果计算，成长更换技能后刷新 |
| 光环 | 只处理套装光环，漏掉领悟光环和百分比护甲 | 处理强弩、百分比护甲、攻击速度、回复与移速；按 self、nonsapper 等目标限制应用 |
| 状态叠加 | 每次攻击都叠一层相同减速，导致怪物越来越慢 | 同一原生状态刷新时长，避免重复乘算；持续伤害在辅助单位移除后继续结算 |
| 波次单位 | 从遗留武器字段推断波次单位能攻击 | 尊重 weapsOn；原表 56 波怪物关闭武器，不再对附近召唤物额外攻击 |
| 移动命令 | 召唤单位在执行移动时仍发起普通攻击 | 明确移动期间抑制攻击，到达后恢复自动寻敌；兵工厂子兵使用集结点 |
| 效果资源 | 只读施法技能模型，漏掉 BuffID、EfctID 中的状态和区域模型 | 递归补全引用，新增 51 个 MDX 和 31 个贴图资源；状态模型随单位移动、刷新并在结束后销毁 |

## 仍不能宣布完全等价的部分

攻击前摇与转身时间尚未按原客户端的动作帧完整模拟；引导技能已补齐上述命令与控制状态的打断，精确到施法帧和原生特殊边界的行为仍需实机对照。同类型不同 ID 状态的强弱覆盖优先级，以及兽群冲撞的随机队形也需与原客户端对照。当前兽群已具备移动、碰撞和范围伤害，不能据此宣称随机轨迹逐帧相同。

部分原图技能提示文字与对象字段本身不一致。例如多重箭说明中的目标数与 DataC、疾病云雾的文字伤害与 DataB 存在差异。本轮按对象字段与 JASS 修复，没有按提示文字擅改平衡；这些特殊原生能力仍需要原版实机结果来确定最终语义。

模型资源完整也不等于画面逐像素相同。粒子生成、光照、透明混合、模型附着点和原版相机下的最终结果，仍应使用同版本 Warcraft 客户端录像或截图做对照验收。

字段语义参考使用了固定版本的 [World Editor 能力字段表](https://cdn.jsdelivr.net/gh/sumneko/w3x2lni@82916514a12b7edb15252d42225cd8cc8ce61cfd/data/enUS-1.27.1/mpq/Units/AbilityMetaData.slk)；伤害类与护甲处理交叉核对了 [Warsmash CUnit](https://cdn.jsdelivr.net/gh/Retera/WarsmashModEngine@f9e0aeed4be372d6016519d0e97b384aa873f374/core/src/com/etheller/warsmash/viewer5/handlers/w3x/simulation/CUnit.java)。这些参考帮助解释归档字段，不能替代原客户端实测。

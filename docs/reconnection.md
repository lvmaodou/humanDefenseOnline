# 掉线重连与对局退出

- 大厅期间空位保留，真人仍可加入；首波开始时未加入的空位由机器人补齐，并在六个原职业中均衡选择。机器人按职业自动建造可用攻击建筑并升级，仍受原有资源、前置条件、地形和施工时间校验。
- 全员离线时先暂停战局；每个断线席位保留 60 秒重连窗口，超时后由机器人接管原席位和已有单位，战局继续运行。玩家用原凭据回来后立即收回控制，资源、职业、建筑和进度不变。无人连接的房间最多保留 30 分钟，原玩家可以在此期间凭据返回。

- 加入房间后，服务器向本人发放随机重连凭据；浏览器保存在本机。断网会自动重试，刷新、关闭页面后重新打开同一网址也会恢复。
- 凭据对应原房间、原玩家和原席位。重连直接接回原来的游戏实例，不重新初始化职业、资源、农民、建筑、库存、技能冷却、套装或波次。昵称和房间码不能用于冒领离线席位。
- 临时离线只改变连接状态，参战状态仍然保留，避免触发原图对退出玩家的金币分配。在线队友继续战斗，离线玩家的建筑继续执行已有命令；资源赠送列表只包含在线队友。
- 同一玩家在另一页面返回会替换旧连接。旧页面停止自动重连，显示“重新连接”，避免两个页面互相抢占。失效旧连接的操作与关闭事件不会再影响当前连接。
- 连接恢复前禁止发送操作，重连时不重放建造、赠送、丢弃、施法等请求；已送达但未收到回执的操作，以恢复后服务器状态为准。
- 地形和原版模型只在页面内初始化一次，自动重连不会重复创建树木、地形和特效管理器。

## 返回首页与结束对局

- 胜利和失败均显示结算页，可选择“返回首页”或“查看战场”；查看后仍可通过顶部“返回首页”退出。模式及职业选择面板也提供返回入口。
- 收到胜利或失败状态后立即清除这局的浏览器重连记录，刷新或重新打开网址会显示首页，不再接回结束的战局。结束后网络中断也不会继续自动重试。
- 旧版页面遗留的重连凭据如指向已结束的房间，服务端返回 `GAME_FINISHED`，浏览器清理该记录并回到入口，清空房间码，可以直接创建新房间。
- 点击“返回首页”代表主动退出本局，清除本人凭据，释放本人席位；与直接关页面或暂时断网不同，主动退出后不再恢复该身份。其他离线队友仍可凭自己的记录返回，正在进行的战局保持原来的掉线保留规则。
- 入口自动重连期间可点击“取消重连，返回首页”，无需等待旧服务器恢复或手动清理浏览器数据。
- 结束的房间在无人连接时释放。复用房间码的新对局不会被旧连接的延迟关闭事件删除；旧页面结束或退出时也不会清除另一个页面保存的新局凭据。

当前战局保存在服务器内存中。重启服务器或清除浏览器本地存储后无法恢复旧身份；过期或无效凭据会明确提示并返回入口，不会悄悄创建新玩家。

验证：`npm test` 包含真实 WebSocket 重连和会话生命周期用例；`npm run test:reconnect` 使用桌面与竖屏手机浏览器验证断网、刷新、关闭再打开、跨页面接管，以及农民装备和资源保留。

`npm run test:exit` 验证桌面和竖屏手机上的胜负结算、查看后退出、刷新、新建对局、旧凭据访问、主动退出、取消重连。截图与报告：`artifacts/match-exit-desktop.png`、`artifacts/match-exit-mobile.png`、`artifacts/match-exit.json`。

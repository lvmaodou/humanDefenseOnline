# 资源赠送与职业套装

掉落池、概率、模型接入及逐物品验证见 [掉落物与原图核对](item-drop-parity.md)。

## 操作方式

- 点击农民，或使用右下角「农民」按钮、F1，打开玩家面板。选择「赠送资源」，指定在线队友和金币、木材数量后提交。
- 点击地面掉落物品可由农民拾取，也可以展开农民面板中的「地面装备」逐件拾取。物品栏有六格，每件装备提供独立的使用、丢弃操作。丢弃后其他玩家可以拾取。
- 套装物品是一次性建塔道具。选择「选择位置建造」后点击绿色地格，农民会在原图施法距离内开工；距离较远时先寻路靠近。道具在实际开工时消耗，无法建造时保留。
- 初级套装塔永久存在。建成后点击建筑，按原图的费用、人口和时间升级为正式套装塔。普通模式下需要对应职业、三种不同组件、任意两塔距离不超过 1200 码；疯狂模式解除职业限制，距离为 99999 码。农民面板展示套装进度和缺失组件。

## 原图逻辑与修复

依据 `content/original-3.0/script.j` 中的 `Trig_TZAllUnit_Actions`、`Trig_TZjianta_Conditions`、`Trig_TZjianta_Actions`，以及物品 `I001`～`I00I` 的 `AIbl` 技能和目标单位 `Upgrade` 字段生成六职业组件关系。

原实现将 `AIbl` 的持续字段错误用于召唤物寿命，并且没有升级完成事件。本次将套装道具接入建造、升级流程，保留原图触发器添加套装能力及三条连接特效。升级保留原单位句柄，使原图缓存中的组件引用有效，并在客户端更换单位模型。

| 职业 | 集齐后效果 |
| --- | --- |
| 野蛮人 | 打狗棒法：按原图 10% 概率附加 10000 点基础技能伤害和 600 秒定身式眩晕，结算保留原图伤害倍率。 |
| 猎人 | 破甲光环：1000 码内敌军护甲降低 30。 |
| 盗贼 | 高科技掠夺：原图偷术、抢劫奖励提高 50%，整数结算。 |
| 术士 | 辉煌光环：800 码内友军额外恢复 3 点魔法/秒，相当于套装法师基础 10 点/秒恢复的 30%；对魔剑士无效。 |
| 游侠 | 身手敏捷光环：700 码内友军攻击速度提高 30%。 |
| 魔剑士 | 邪恶光环：1200 码内敌军移动速度降低 25%。 |

同一光环来自三座套装塔时不重复叠加。光环使用原始 MDX 表现；套装连接持续显示，原图 `-guanbi`、`-kaiqi` 指令可关闭、恢复连接。

资源赠送在服务端一次性检查双方玩家、在线状态、整数数量和资源余额；校验全部通过后才同时扣除和增加资源，客户端等待确认后显示成功。

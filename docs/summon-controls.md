# 召唤物的选中与移动

原先地面单击只为六种职业农民发送移动指令，选中普通召唤物后会进入建造流程。现在己方可移动单位共用地面移动操作，保留当前选中单位与信息面板；桌面右键移动继续可用。

移动能力由服务端按原图单位数据判断：存活、未移除、非建筑且实际移动速度大于零。水元素、树人、狼、熊、炎魔和地狱火均可移动；兵工厂等零移速召唤物可以查看信息，但不能发送移动指令。建筑、已死亡单位和其他玩家的单位不能通过伪造请求绕过校验。

原图将多数职业召唤物设置为 `movetp=fly`，包括外观站在地面的水元素、狼、熊等。寻路现按原始移动类型分别读取 WPM 的地面阻挡位 `0x02` 和禁止飞行位 `0x04`，飞行单位不会被地面单位碰撞挡住。地面召唤物保留地面寻路限制，飞行单位仍遵守原图禁止飞行区域。

手动移动会清除此前指定的攻击目标，保持召唤持续时间、归属、移速上限和定身等效果。农民继续承载建造、图鉴和装备等玩家操作。

验证：`npm test` 覆盖原图六类技能召唤、地面和飞行障碍、零移速、归属、定身与死亡检查；`npm run test:summons` 在真实服务器和桌面、竖屏触摸浏览器中选中水元素、狼、熊并点击地面移动，同时检查固定兵工厂不会误进入建造流程。

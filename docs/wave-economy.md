# 波次金币异常修复

原图的 `Trig_NextRound_faqian` 累加波次奖励：普通模式为 `波数 × 6 + 50`，疯狂模式为该值的 1.5 倍取整，第一波不发放。击杀赏金另外累计。

金币减少来自 `Trig_GetP1`～`Trig_GetP5`：这组触发器用于玩家真正退出后的资源分配，每 120 秒执行一次，并清零对应玩家的金币。原图初始化时关闭它们，只有 `Trig_P1Leave`～`Trig_P5Leave` 才会开启。

引擎原先只在普通事件派发时检查触发器开关，定时事件遗漏了检查，导致关闭的退出触发器仍定时清零、转移在线玩家金币。现在定时事件也检查开关；计时周期继续推进，重新开启后不会补执行停用期间的事件。原图显式调用 `TriggerExecute` 的行为保留。

验证：

- `npm test`：72 项通过。新增回归在六个职业、四个玩家中运行六波原图刷怪与击杀结算，逐次检查金币变化，跨过 120、240、360 秒；另检查周期事件的关闭、开启、销毁，以及关闭的一次性事件不会重放。
- `npm run test:economy`：独立真实服务端搭配桌面、竖屏手机两个 Chrome 客户端，检查第一波各 40 次击杀得到 940 金、第二波开始各增加 62 金，并跨过三次 120 秒周期核对服务端余额与页面标题栏。
